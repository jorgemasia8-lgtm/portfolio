De la URL a la página

  1. Escribo una URL en el navegador (cliente).
  2. El DNS traduce el nombre del dominio a la dirección IP del servidor.
  3. El navegador envía una petición HTTP al servidor web.
  4. El servidor responde con el HTML, que puede enlazar imágenes y otros recursos.
  5. El navegador interpreta el HTML y muestra la página.

Herramientas que uso
