# Portfolio de Jorge Masià

Portfolio personal del módulo **Lenguaje de Marcas y Sistemas de Gestión de Información** (curso 2026-2027). Es la primera versión (v1): cinco páginas en HTML5 semántico, válidas según el validador del W3C y sin CSS, que se diseñarán en el segundo trimestre.

Publicado en: https://jorgemasia8-lgtm.github.io/portfolio/

## Páginas
| Página | Contenido |
|---|---|
| `index.html` | Presentación, qué busco y tres proyectos destacados |
| `sobre-mi.html` | Trayectoria, aficiones e intereses y objetivos |
| `proyectos.html` | Siete proyectos del trimestre, con lo que aprendí en cada uno |
| `cv.html` | Currículum con tablas de formación y competencias, e idiomas |
| `contacto.html` | Formulario de contacto validado, correo y GitHub |
| `entorno.html` | Mi entorno de trabajo (proyecto enlazado desde `proyectos.html`) |

## Tecnologías
- HTML5 semántico y accesible
- Git y GitHub
- Visual Studio Code con Live Server
- Validador del W3C (Nu Html Checker)

## Estructura

portfolio/

## Cómo verlo en local
Abre la carpeta en VS Code y lanza `index.html` con Live Server.
